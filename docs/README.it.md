# Documentazione di Dropwheel

Dropwheel è una ruota radiale di azioni sui file: trascini dei file, tocchi <kbd>Shift</kbd>, li rilasci su un
settore e vengono convertiti, compressi, ritagliati, oscurati o condivisi, tutto in locale. Queste pagine
spiegano come installarlo, usarlo ed estenderlo.
